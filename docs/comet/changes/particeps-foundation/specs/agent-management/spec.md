# 母机 Agent 管理与监控

状态：完整目标规格，等待最终 Shape 确认。功能选择来自 brief 的用户决定；工程默认值与验收一并提交完整确认，当前没有实现或通过验收的结论。

## 产品边界

本项目交付母机 Agent，内置管理本母机的 Web 面板与版本化 API，后端为 Incus 系统容器。

## Incus 系统容器

小鸡运行完整 Linux 用户空间，与母机共享内核。Agent 的管理 ID、Incus 容器和采集对象必须对应。首期以 Debian 13 x86_64 及 Debian 官方 Incus 6.0 系列容器包为验证基线，启动时检查所需 API 能力。对应 A6。

## 实例归属与接管边界

首期管理 particeps 新建的小鸡，在专用 Incus 项目中保存明确的归属标识。已有或其他工具创建的实例不会被自动接管、修改或清理。管理记录与实际对象不一致时展示异常，不以清理“幽灵实例”的方式删除未知资源。已有实例接管和 runman-agent 迁移另行设计。对应 A27。

## 系统镜像与初始化

提供 Alpine 与 Debian 13，默认 Alpine。发行配置记录采用的稳定版本、来源和镜像指纹，已有小鸡不会因远端标签更新而被静默替换。实际创建系统必须与选择一致，记录其镜像来源。对应 A36、A37。

管理员可登记本机已导入的 Incus 镜像，供创建和重装选择；未登记镜像不会出现在默认选项中。登记前核对本机别名或指纹确实存在。对应 A67。

创建参数包含名称、镜像、CPU 额度、可选 CPU 编号、内存上限、系统盘额度、网络栈模式、SSH 公钥和密码登录设置。默认实验模板为：Alpine 0.5 核 / 128 MiB / 1 GiB；Debian 13 0.5 核 / 256 MiB / 4 GiB；均可调整。额度与实际占用分别显示，操作前检查参数和存储余量，不承诺同时用满所有额度。

创建阶段至少区分镜像准备、容器创建、网络配置、登录初始化和就绪核对。镜像或初始化失败落到对应实例任务；Incus 显示 running 不等于 SSH 初始化或外部网络验证完成。

重装更换系统盘内容，保留管理身份、资源配置、IP 分配、端口归属和已配置的转发目标。重装表单默认保留公钥，密码按本次请求设置或重新生成；执行前展示所选实例、目标镜像和系统盘数据替换影响。

## SSH 登录

支持导入公钥，初始化后能够用对应私钥通过网络 SSH 登录。对应 A38。A38 验证的是持有该私钥的 SSH 路径，不授予也不取消管理员 Web 终端。

导入的公钥可以是使用者的密钥。管理员若未持有对应私钥，则不能用这条 SSH 路径登录；这不影响 Web 终端。管理员仍可用自己持有的公钥、已启用的密码，或密码重置后的 SSH 登录。

支持逐实例设置或自动生成初始密码，生成值不使用所有小鸡共用的固定默认密码。关闭密码登录时禁用 SSH 密码认证及等价的密码交互认证路径，已配置公钥仍可用于 SSH；仅公钥模式必须提供有效公钥。对应 A39、A40。

密码不进入普通实例列表、查询结果或日志。自动生成的初始密码只在受保护的初始化交付中提供；异步初始化临时所需的凭据加密保存并在完成后清除，读取权限限定为管理权限。遗失后可通过已授权密码重置或 Web 终端重新设置，不提供长期明文密码查询。对应 A54、A60。

管理员可对运行中小鸡重置密码。启用密码登录时新密码可用于 SSH；仅公钥模式仍可在系统内设置密码，但 SSH 密码认证保持关闭。重置通过受控执行通道完成，等待实际结果，不以命令被接受代替成功。对应 A60。

## Web 面板与 API

面板提供概览、实例列表与详情、批量任务、资源图表、终端和设置。概览显示母机 CPU、内存、磁盘、负载、运行时间、上行实时速率，以及受管小鸡合计 CPU 用量与合计硬上限。实例列表显示每台当前 CPU、内存占用和网络速率，并支持按这些字段排序。选定小鸡详情可打开内部进程诊断。浏览器与外部程序调用同一套业务规则和数据。对应 A4、A5、A64、A65、A81。

使用 /api/v1 HTTP JSON API，提供 OpenAPI 契约和示例。长任务返回任务 ID，状态查询返回逐实例步骤与结果。未认证请求拒绝访问管理数据；单管理员会话和独立 API Token 分离，Token 支持只读与管理两类权限及撤销。只读权限不能修改实例或打开终端。对应 A53、A55。

接口只操作本系统受管资源，不透传任意 Incus API、宿主命令或文件路径。Web 状态变更与终端会话执行身份和来源校验。

## Web 终端

有管理权限的管理员可在实例详情打开运行中小鸡的交互终端。该通道经 Agent 与 Incus 执行会话进入实例，不使用导入的 SSH 公钥、私钥、密码或 22 端口映射。即使仅导入他人公钥、关闭密码登录、SSH 服务未就绪或端口映射不可用，只要 Agent 与 Incus 可用，管理员仍可进入。支持输入、输出、窗口尺寸变化和关闭；窗口尺寸变化必须送达实例内会话，不能丢弃。对应 A41。

会话绑定实例和有管理权限的调用者。停止实例不能被终端查询自动启动；断开或超时只清理终端会话，不停止小鸡。记录会话起止和目标，默认不记录输入内容。首期不提供母机交互终端。

### 执行与恢复

默认同时处理最多 2 台，可调整；不同小鸡可并发，同一小鸡的生命周期与改配串行执行。任务、逐项步骤和 Incus 操作引用持久化，关闭浏览器不取消任务。对应 A43。

单台失败继续处理其他独立任务，成功项保留，失败项记录原因。重试只针对需要重试且可安全重复的失败项。全局依赖不可用时停止派发新动作并报告依赖异常，不持续创建无意义的失败任务。对应 A44。

创建、批量重装等变更接口使用幂等键。相同键和请求返回已有任务；同键不同请求冲突拒绝。详细任务记录默认保留 30 天，未完成和待核对任务不自动清理；精简幂等标记继续用于拒绝重复执行。对应 A45。

Agent 重启后读取已有任务和 Incus 状态，区分未开始、执行中、已完成和结果不明。先核对再恢复；结果不明的重装进入待核对状态，不能盲目重新执行。对应 A46。

每台小鸡保存期望运行或停止状态，并设置 Incus 对应的开机自启。母机或 Agent 重启后，期望运行的恢复运行，用户停止的保持停止；不得把“创建时曾为 running”误当成当前应运行。对应 A66。

## 端口分配

支持创建时分配连续号段，以及对已有小鸡追加或指定单端口。对应 A16、A17。

默认池 20000–59999，每台初始分配 20 个连续端口号，池和数量可调整。20 是初始数量，后续追加使用仍可用的号码。同一入口号码的 TCP/UDP 归同一小鸡，按号码而非协议规则条数计数。对应 A29。

号段首个 TCP 端口映射到 22；其他 TCP 和全部 UDP 默认同号。例如 20000–20019 对应 TCP 20000→22、TCP 20001–20019→同号、UDP 20000–20019→同号，不另外占用 SSH 号码。对应 A30。

目标端口可编辑，修改后实际转发和界面使用新目标，号码归属保持不变。界面以实际配置判断 SSH 入口。对应 A31。

停机、重启、重装保留号段、单端口和自定义目标；内部地址变化时更新规则关联。实例删除成功且相关转发清理完成后回收，清理失败保留占用和待处理状态。对应 A32、A33。

分配使用统一记录并核对 Incus 规则与母机已有占用。自动分配跳过冲突，手工冲突明确拒绝，不覆盖已有使用者。并发请求不能获得重叠号码。修改默认池只影响后续分配，不自动收回已使用号码。展示分配与规则生效状态，外部可达性另行验证。

可为全部受管小鸡设置默认的唯一来源 IP 上限，也可按小鸡覆盖；0 表示不限制。统计的是当前对该小鸡已映射入口仍保持连接的不同来源地址，不是协议规则条数。达到上限后，新的来源 IP 被拒绝；已经在限额内的来源可以继续建立多条连接。面板显示当前活跃来源数与生效限额。对应 A69。

### 内核转发路径上的连接跟踪

同地址族入站流量走 Incus 写入的内核 DNAT，不经过 Agent 进程。DNAT 只改目的地址，**源地址保持为真实客户端**。

每条连接进入 conntrack 后可看到：客户端源地址、母机上的入口地址与端口、翻译后的小鸡地址与端口。Agent 按小鸡把其已映射入口归为一组，对该组维护「当前仍有连接的唯一源地址」集合：

1. 新连接（conntrack 状态 NEW）到达某台小鸡的映射端口。
2. 若该源地址已在该小鸡的集合中，放行；同一源地址允许多条连接。
3. 若是新源地址：限额为 0 或不限制则加入集合并放行；已达上限则拒绝该新连接。
4. 该源地址的最后一条连接关闭或超时后，从集合中移除。

后续网络限制（每源并发连接数、新建速率、地址黑白名单等）挂在同一观察点：同一套 conntrack/nft 钩子，按小鸡的映射端口组匹配。不因此改回用户态代理。

## 母机公网资源与小鸡网络

Agent 检测上行接口上的全局 IPv4、全局 IPv6 以及可识别的 IPv6 前缀（含管理员补录的路由前缀），在 Web 展示地址、接口和来源。对应 A70。

管理员勾选小鸡允许使用的 IPv4、IPv6 地址和前缀。未勾选的不用于新分配或新映射。可把某 IPv4 标为 NAT/映射入口，把额外 IPv4 标为可独占分配。对应 A71。

按池内实际能力提供：

| 能力 | 条件 | 行为 |
| --- | --- | --- |
| IPv4 SNAT | 池中有 IPv4 | 小鸡出站 IPv4 源地址改写为指定 NAT IPv4 | A72 |
| IPv4 DNAT/端口映射 | 池中有 IPv4 | 在指定公网 IPv4 上监听映射端口，转发到小鸡 | A73 |
| 独立公网 IPv4 | 池中有可独占的额外 IPv4 | 1:1 分配给小鸡，不再分给其他小鸡独占 | A74 |
| IPv6 NAT66 | 有 IPv6 地址但无可用前缀，或管理员选择 NAT66 | 出站 SNAT，入站可在该 IPv6 上 DNAT/端口映射 | A75 |
| 独立公网 IPv6 | 池中有前缀 | 从前往每台分配地址；路由前缀走直路由，同链路前缀做必要的邻居代理 | A76 |

创建时选择 IPv4-only、IPv6-only 或双栈，且必须被当前池支持。Web 只列出可支持的模式，不支持的组合拒绝并说明缺哪类资源。对应 A77–A80。

有可用 IPv6 前缀且该次创建允许 IPv6 时，**优先独立公网 IPv6**，不用 NAT66。无前缀但有 IPv6 地址时才用 NAT66。对应 A35、A76。

IPv6-only 小鸡只提供 IPv6 连通性；不把 IPv4 映射做到 IPv6-only 小鸡（不做 NAT46/NAT64）。母机没有 IPv4 时，IPv4 NAT/DNAT 不可用。对应 A78。

只管理本项目网桥、地址分配和转发规则，不清空母机既有规则。检测结果不是外部可达证明；真实公网路径另行验证。

## CPU 分配

用户可见的“N 核”表示 CPU **时间硬上限**，不是 vCPU 个数，也不是必须绑核。0.5 核 = 每个 100ms 周期最多使用 50ms CPU 时间。首期写入 Incus `limits.cpu.allowance`（0.5 核为 `50ms/100ms`），不用 `50%` 软限制，也不把 0.5 核写成整数 `limits.cpu=1`。该口径与 cgroup CFS 配额相同，后续若扩展 Podman，映射为 `cpu.cfs_quota_us=50000`、`cpu.cfs_period_us=100000`（或等价 CPUQuota）。首期不交付 Podman。对应 A18。

默认由系统在允许的逻辑 CPU 中调度；可指定逻辑 CPU 编号，取消绑定解除该实例编号限制并保留额度。对应 A19。

允许 CPU 超分：单台额度之和可以超过母机逻辑 CPU 数，也可以超过下面的合计硬上限。统计所有存续受管实例的已配置额度，同时展示母机逻辑 CPU 容量、合计硬上限和超分倍率；2 vCPU 配置合计 8 核时为 4 倍。额度不是最低算力保证，绑定不是物理核心独占。对应 A47。

另设**小鸡合计 CPU 时间硬上限**。所有受管小鸡的实际 CPU 时间合计不得超过该值，与开了多少台、单台额度加起来多少无关。出厂默认为母机逻辑 CPU 数的 75%（2 核母机为 1.5 核），管理员可在 Web 调整，运行中生效。单台额度仍是该台硬上限。单台额度大于合计硬上限的创建或改配被拒绝。该上限只约束受管小鸡，不限制 Agent、Incus 守护进程和母机系统进程。对应 A81。

有效改配运行中生效，核对 Incus 实际配置并持久保存。不可用 CPU 编号、不可执行额度及超过所选 CPU 集合能力的单实例配置拒绝执行，不静默截断或重启小鸡。重启后保持配置。对应 A48。

内存上限可在运行中调整，Agent 展示值与 Incus `limits.memory` 相符。对应 A61。

系统盘额度只允许提高；提高后实际 Incus 磁盘限制与配置一致。降低额度明确拒绝。对应 A62。

网络带宽上限以 Mbps 配置，0 表示不限制。非零值应用到 Incus 网卡入出站限制，运行中可改配。对应 A63。

## 监控分层

日常监控以资源用量为主，不以进程列表作为主视图。对应 A20–A24、A64、A65、A68。

| 层级 | 对象 | 内容 | 用途 |
| --- | --- | --- | --- |
| 母机概览 | 母机 | CPU、内存、磁盘、负载、运行时间、上行实时速率，以及小鸡合计 CPU 与合计硬上限 | 看母机是否过载、小鸡合计是否顶到总帽 |
| 实例列表 | 全部小鸡 | 当前 CPU、内存占用、网络速率，可排序 | 一眼找出占用高的小鸡 |
| CPU 图表 | 母机与每台小鸡 | 实时图与保留范围内的历史曲线 | 看趋势和额度使用比例 |
| 网络图表 | 母机与每台小鸡 | 入出站实时速率、累计观测流量与历史曲线 | 看带宽与流量趋势 |
| 周期流量 | 母机与小鸡 | 当前统计周期累计观测流量，可手动重置 | 粗看用量，不是计费账本 |
| 进程诊断 | 仅选定小鸡 | 该小鸡内部进程的实时 CPU、内存与排序 | 进入详情后定位其内部高占用 |

不提供母机进程列表。母机侧只采集资源计数器（CPU 时间、内存、磁盘、负载、上行接口流量），不展示 `/proc` 全机进程表。

## 网络监控

母机与小鸡分别提供入出站实时速率、累计观测流量和历史曲线。母机统计配置的上行接口，小鸡统计自身非回环接口，避免把桥接和上行流量重复当成母机外部流量。API 明确使用字节和字节/秒，界面转换显示。对应 A20、A21。

计数器重置和未覆盖期间保留数据质量信息，累计观测流量不作为准确计费账本。可查看当前统计周期的累计观测流量，并手动重置周期计数；重置不影响历史曲线、管理数据或未完成任务。首期不包含连接明细、按进程网络归因或流量超额自动处置。对应 A68。

## CPU 监控

母机展示总体和逻辑 CPU 使用情况，小鸡展示已用核数及占当时有效额度的比例，并提供历史曲线。Incus 累计 CPU 时间通过相邻采样差分换算，母机比例按可用逻辑 CPU 总量归一化。对应 A22、A23。

配置 0.5 核、实际使用 0.25 核时显示 50% 额度使用率；样本关联当时有效配置，后续改配不重算过去比例。对应 A52。

## 进程诊断

仅在选定小鸡的详情中查询该小鸡内部进程，结果明确标识该实例。切换小鸡后返回新选小鸡内部进程，不能返回母机进程，也不能用母机上的容器运行进程或 Incus 进程总数冒充内部列表。对应 A7、A24。

结果包含 PID、名称、用户、状态、启动标识、实时 CPU 和驻留内存，支持按 CPU/内存排序及按名称/PID 查找。使用 PID 与启动标识防止复用混淆。

通过母机侧实例身份、cgroup 与 PID 命名空间建立对应关系；实际实现须在目标 Linux 环境核对。首期仅提供实时进程视图，不保存全量进程历史，也不提供结束或重启进程的管理功能，不提供母机进程列表。

## 采样与历史

默认 CPU/网络每 5 秒后台采样。打开选定小鸡的进程视图时每 2 秒刷新该小鸡；切换或离开页面取消旧请求与高频查询。参数可调整。对应 A49。

原始资源样本保留 24 小时，1 分钟汇总保留 30 天，保留平均和峰值。历史按查询范围选取合适粒度，过期清理只处理监控数据。对应 A50。

数据包含采样时间和有效性状态。首次差分不足、计数器重置、缺测与采集失败不能产生负速率或虚构零值；保留最后有效时间，历史缺口明确呈现。已停止实例的真实零消耗与采集失败区分。对应 A51。
