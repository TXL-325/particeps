# particeps 项目基础

状态：完整目标规格，提交最终 Shape 确认；当前不表示已实现或已通过验收。

## 项目身份与工作区

particeps 是独立项目，在 particeps 工作区维护需求、规格和实现。runman-agent 仅作为对照与实现参考，本 change 不修改参考仓库。对应 A1。

## 产品目标

本项目交付母机 Agent，管理 Incus 系统容器，内置 Web 面板与对外 API。核心能力为完整批量生命周期（含强制停止与密码重置）、小鸡端口分配、按母机公网资源组合的 IPv4/IPv6、CPU/内存/磁盘/带宽、网络与 CPU 实时/历史监控、母机概览，以及选定小鸡内部进程诊断。

完整行为以 [管理与监控规格](../agent-management/spec.md) 为准，技术栈、部署、工程默认值与验证方式以 [实现方案](../agent-architecture/spec.md) 为准。各能力映射到 brief 的有效验收项，不以“更完善”等宽泛表述代替验证。

## 产品范围

本项目专注于母机 Agent。对应 A3。

Agent 的 Web 面板和 API 在母机侧独立使用，覆盖相同管理与监控行为；外部程序可通过 API 调用。对应 A4、A5。

首期只管理 particeps 新建小鸡，不自动接管或清理已有 Incus/runman-agent 实例。对应 A27。

提供 Alpine 和 Debian 13，默认 Alpine（0.5 核 / 128 MiB / 1 GiB）。“N 核”为 CPU 时间硬上限；另有小鸡合计硬上限，默认母机逻辑 CPU 的 75%。支持 SSH 公钥、逐实例密码及关闭密码登录；管理员进入小鸡使用不依赖该公钥的 Web 终端。网络按母机已勾选的 IPv4/IPv6 资源组合，有前缀时优先独立公网 IPv6。

用户逐轮选择与修正的完整记录保存在 brief 的 Source coverage。当前范围以 A3 为准。

## 本地验证环境

用户在 Win11 上使用 VMware Workstation，准备 Debian 13 x86_64 母机，2 vCPU / 4GB RAM / 50GB 虚拟磁盘。容量数字来自用户明确回答，实际磁盘余量和接口配置在实施时核对。对应 A25、A42。

通过本地网络模拟 IPv4、IPv6 和上游 NAT，区分测试客户端、母机和 Incus 小鸡所在位置，记录完整路径与实际结果。本地模拟不能直接证明真实互联网可达性。对应 A26。

每台母机目标为 8–16 台小鸡，原“816 台”已由用户纠正。在 8 台和 16 台轻负载场景验证管理与监控，记录镜像、资源额度、实际负载和 Agent 开销；压力验证在受控实例单独进行，不将数量目标视为全部实例同时满载的保证。对应 A28。

用户负责准备模拟环境；实施可先完成不依赖 VM 的工作，实机验收需要其准备好的测试环境和真实证据。当前文件不表示 VM 或测试网络已经建立。
