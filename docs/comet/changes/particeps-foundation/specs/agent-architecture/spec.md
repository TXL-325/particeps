# 母机 Agent 基础交付实现方案

本规格负责模块关系、执行边界、持久化、后端协调及验证机制。用户可见的部署行为见[项目规格](../project-foundation/spec.md)，实例操作规则见[管理规格](../agent-management/spec.md)；需求来源与决定见[brief](../../brief.md)，阶段与结果由 Runtime 管理。后续首期方案保留在[完整首期架构](../../../../../planning/first-release/specs/agent-architecture/spec.md)。

## 运行与配置

Go Agent 构建为 Linux amd64 二进制，Vue 3/TypeScript/Vite 的静态前端嵌入其中，由单个 systemd 服务提供面板与 /api/v1；母机不需要 Node 服务。通过本地 Incus Unix socket 管理系统容器。实验后端基线为 Debian 13 Incus 6.0 系列，记录实际版本和所用能力。对应本次 A1。

程序、配置和管理/监控数据库仍使用 /opt/particeps、/etc/particeps、/var/lib/particeps 的既有布局。只写本项目路径，保持数据目录单写者；不复用或格式化归属不明资源。

现有 App.Close 方法会停止并等待采样循环；实际进程退出路径的接入与验证仍待完成。本次须验证 Agent 停止/重启不影响已运行小鸡、有效转发及既有连接，重启后管理记录可查询。HTTP/任务的完整优雅退出与持久恢复仍按后续范围处理，不能把 Close 方法存在当作实际退出或全部恢复已完成。对应本次 A11。

## 部署与发布

交互控制必须区分等待输入的静态页面和正在执行的任务。主菜单、参数输入、执行前确认、结果页和日志页 Ctrl+C 直接退出脚本；首次安装、更新、恢复备份、仅卸载 Agent 执行时 Ctrl+C 记录软中断请求，阻止后续正常步骤，下载或只读步骤及时结束，正在写入或恢复文件、处理软件包及变更资源的步骤先安全结束再进入回退。回退期间重复中断不重新发起回退、不硬杀恢复过程。首次安装回退按安装前软件包清单移除本次新增包（含新装 Incus 与依赖），并删除或恢复本次写入的程序、配置、数据和专用资源。全部卸载与 Incus 清除开始后忽略 SIGINT，命令失败仍停止后续步骤。查看状态查询中的中断只停止查询。

每次操作使用独立的严格错误处理边界，失败后不继续正常步骤。任务结束释放锁并清理本次暂存文件；菜单切换重置动作标志。失败结果显示动作、原因、实际变更或尚未确认的结果及诊断日志位置，等待回车返回原菜单。软中断的清理和回退分别核对，回退失败保留恢复所需材料并显示失败原因，不能返回“已恢复”结果。终端输入结束时安全结束会话，非交互调用失败返回非零且不等待输入；可软中断的命令行操作完成回退后以中断状态退出。

保留五项操作与主菜单 0 退出。无效输入在当前菜单重新选择；修改操作提供执行摘要，参数即时校验并在本次会话保留非敏感选择。结果页可查看日志；只有未进入不可安全重复的变更阶段时提供人工重试，重试重新预检，卸载仍须重新经过原确认。任务显示分阶段进度；安装、升级和回滚在需要服务运行时核对真实 systemd 状态，原停止的升级继续保持停止。诊断日志位于独立于 Agent 数据的受限目录，初始管理员密码仅送达终端，不进入日志。对应本次 A13。

`deploy/install.sh` 是唯一安装入口，由 GitHub Release 分发，不接受本地二进制旁路。tag 触发的 GitHub Actions 交叉编译 linux amd64、计算 SHA256，并上传 Agent、`install.sh` 与校验和文件。下载先落到临时文件，校验 SHA256 和 ELF64 后再替换 `/opt/particeps/particeps-agent`。对应本次 A13。

资源名称、池大小建议与输入边界、IPv6 补配条件、默认监听和卸载确认按[项目规格的部署与发布](../project-foundation/spec.md#部署与发布)执行。本节只补充实现机制；既有资源的保留与冲突检查仍须满足该规格。

IPv6 检查使用 `ip -6 -o addr show scope global`，按项目规格筛选接口并判断是否补配网桥。脚本只准备网桥，不代替 Agent 的完整实例 IPv6 管理或公网验证。

管理员初始化由安装脚本生成密码，通过临时环境变量 `PARTICEPS_ADMIN_PASSWORD` 调用同一二进制的 `--bootstrap-only`，持久化管理员哈希后退出。初始密码仅由安装终端交付，不进入普通服务日志或 API；密码长度、既有管理员保留及配置默认值按项目规格执行。

已安装检测依据标准路径上的程序、`/etc/particeps/config.yaml` 和 systemd `ExecStart`；不完整安装拒绝升级。升级使用 `/run/lock/particeps-install.lock`。备份目录为 `/var/lib/particeps/backups/upgrade-*`，用 SQLite 在线备份复制管理库，避免只拷活文件丢掉 WAL。服务重启失败时退出非零并打印备份路径。

备份保留程序、单元、配置、state.db 和存在的 metrics.db，不备份实例磁盘，目录权限 0700。升级只替换程序，原停止的服务保持停止；回滚恢复这些文件并核对真实服务与管理数据结果。校验失败不修改现有程序、配置和后端资源，回滚不能用文件存在代替 WAL 数据及运行状态核对。

卸载实现分离 particeps 项目资源删除与后续 Incus 包/数据清理；后者只能由单独的明确交互选择触发。`--keep-instances` 只进入 Agent 停用/移除分支，保留配置和数据，不能到达实例或 Incus 清除流程；非交互保留 Incus。完整确认与影响边界见项目规格。

剩余空间预算和 8–16 台集成仍留给首期 S7。

## 身份、创建与状态

受管实例使用管理 UUID、Incus 名称和明确归属元数据；任务子项、端口归属与查询对象关联。正常创建的任务/子项先落库，再受控执行；默认并发 2 台。当前门槛是正常批量创建及结果可查询，不宣称已有完整的重启任务执行器。对应本次 A1、A4。

Alpine 和 Debian 13 使用明确镜像来源；核对实际系统和模板应用。资源配置继续校验，等待后端终态并保留必要回读。启动失败不能通过移除 raw.lxc/cgroup 限制重试。父/子 CPU 压力、内存/盘/带宽实际限制在后续资源交付独立验证。

## 端口与后端协调

管理 SQLite 保存号码、实例归属、期望规则和待清理状态。分配/修改先登记意图，调用 Incus 后核对结果，未确认时不伪报成功。Incus 按入口地址保存整张 forward，更新时按实例归属合并并保留其他实例。

实际 TCP/UDP 流量走 Incus 管理的内核 DNAT，Agent 不逐包复制。当前使用已核对的实验入口和内部 IPv4；指定出口 SNAT、独立 IPv4、IPv6/NAT66 与完整池能力不属于本次完成声明。

共享入口写入前记录 `forward_writes`，结果不明时阻止该入口危险修改和资源回收；数据目录锁避免两个 Agent 同时写同一账本。固定 Incus 6.0.4 的 If-Match 不能作为已验证并发保护；不支持外部工具同时修改本系统所属 forward。

清理顺序为记录状态、移除本实例规则、精确清理/核对连接、确认实例删除、事务回收。目标更新保留旧连接关联，不能误删新目标或其他实例；失败时保留可查询状态。停止保留账本但暂停映射，启动后观察地址再重绑。对应本次 A5–A9。

## 接口、凭据与界面

单管理员会话与只读/管理 Token 分离，Token 可撤销；会话写入执行来源检查。监听及 Cookie 默认值按项目规格执行，直接 TLS 请求保持 Secure。完整 HTTPS 部署约束继续有效，实验可连接不代表完整公网部署已验证。对应本次 A2、A13。

初始凭据使用受保护的加密暂存与一次领取。交付期为 15 分钟，领取和过期都有清除行为；普通查询只提供可领取状态，不提供长期明文。后台到期清理、错误路径及浏览器清除/迟到响应都需验证。对应本次 A3。

Vue 使用 Composition API 与 script setup，路由组合页面，composable 管理请求/轮询与对象身份，组件渲染端口/状态。切换实例取消或隔离旧结果；修改后新 GET 成功前维持未确认状态。对应本次 A10。

对应当前已交付接口维护 OpenAPI 和示例，文档区分受理、后端状态、端口规则与实际可达。未知结果不隐藏为成功，重装等尚未实现操作明确拒绝。对应本次 A10、A12。

本表定义证据要求；候选版本、检查次数、真实结果及缺口维护在[当前交接](../../../../../quality/current-handoff.md)和对应日期报告。开发检查按[协作约束](../../../../../knowledge/verification-and-workflow-constraints.md)选择，命令入口见[构建与测试](../../../../../development/build-and-test.md)。

| --- | --- |
| 代码与界面 | 相关 Go、Vue 行为检查、类型/构建及独立复核 |
| 创建 | 正常批量至少两实例、Alpine/Debian 实际系统和身份 |

| Web/API | 实际浏览器完成当前操作；API 与新查询结果一致 |
| Agent 生命周期 | 实际停止/重启期间实例、现存转发和既有连接连续 |
| 环境/清理 | 候选版本、硬件、客户端/母机/小鸡路径、前后状态、资源清理 |
