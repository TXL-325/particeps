## 改动情况

| 模块 | 修复结果 | 主要实现 |
| --- | --- | --- |
| 管理员初始化 | 先可靠交付密码文件，再保存哈希；查询和文件失败停止初始化，数据库失败可重试 | `internal/core/bootstrap.go` |
| 登录与会话 | Secure Cookie 默认开启；连接来源、全局和并发登录限制；会话撤销失败向上返回 | `internal/auth/limiter.go`、`internal/api/server.go` |
| Token 后端 | 列表数据库错误可见；空列表为数组；名称/角色校验；不存在的撤销返回 404 | `internal/core/tokens.go` |
| 凭据维护 | 启动、独立周期及读取/领取清理到期凭据和过期会话；改密前使原凭据失效 | `internal/store/secrets.go`、`internal/core/credentials.go` |
| 密码操作协调 | 按规范实例 ID 加锁；改密操作先持久记录；超时结果保留并对账，阻止与启停/删除重叠；等待后严格检查原 ID | `internal/core/authentication.go`、`internal/core/password_operations.go`、`internal/incusx/exec.go` |
| Web 交互 | 独立 Token 加载、签发忙状态、一次性显示/清除、撤销确认及重试、迟到响应保护；登录和退出错误反馈 | `web/src/components/settings/`、`web/src/composables/useTokens.ts`、`web/src/composables/useLogout.ts` |
| API 契约 | 补全 27 个路径、32 个 HTTP 操作的权限、输入输出和错误定义，修正进程启动时间及上游错误状态 | `docs/api/openapi.yaml` |

设置页保留现有样式，网络设置、CPU 总帽与 Token 按职责拆成组件。前端构建产物已同步到 `internal/web/dist`。
