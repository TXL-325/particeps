## guest4 SSH 故障

故障有两个独立原因：Alpine 未安装 SSH 服务，母机直连实例 22 返回 connection refused；Docker 将 FORWARD 策略设为 DROP，而 DOCKER-USER 为空，Windows 入站及实例出网被阻断，表现为超时。

[实验转发脚本](../../deploy/lab/vmnet2-forwarding.sh)补充限定入口、接口、网段和连接状态的规则，对应服务已安装并启用；保持 FORWARD DROP。修复转发后 Windows 从超时变为连接拒绝，Alpine 软件源恢复可访问；随后为 guest4 安装 OpenSSH 并通过 OpenRC 启用，未更改原密码。

Windows 经 `10.90.0.10:20020` 完成 root 密码认证，校验主机密钥并执行命令，返回 `p-e7ade30abd02`、UID 0、Alpine 3.21.7，退出码为 0。全部测试清理后再次认证成功。密码未保存到报告或证据。
