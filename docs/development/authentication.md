# 认证、会话与密码操作

Web 管理员使用 bcrypt 密码和 12 小时会话；自动化客户端使用独立的 `read` / `manage` Bearer Token。Token 只保存摘要，撤销后立即失效。接口的角色、输入、输出和错误定义见 [OpenAPI](../api/openapi.yaml)。

## 会话配置与登录限制

`session_cookie_secure` 默认 `true`，反向代理终止 HTTPS 时也应保持此值。Agent 不依赖客户端提供的转发头来决定是否降低 Cookie 安全属性。直接 TLS 请求始终使用 Secure Cookie。

通过远端普通 HTTP 实验网访问时，须在隔离的开发配置中显式设置：

```yaml
session_cookie_secure: false
```

该选项只控制会话 Cookie，不会给 HTTP 提供加密；HTTPS 部署应恢复 `true`。

登录入口按实际连接来源限制每分钟 5 次，整个 Agent 每分钟 30 次，同时最多执行 2 次密码校验；成功和失败尝试均计数。拒绝时返回 `429` 和 `Retry-After`。转发头不能绕过限制；经同一个反向代理接入的客户端共享该代理来源的限额。

退出会话必须成功删除数据库记录。删除失败返回错误，浏览器保留页面和会话，允许重试。

## 初次管理员初始化

初始化先将密码写入数据目录中的 `admin-bootstrap.txt`，同步文件和目录后，再保存密码哈希。文件权限为 `0600`，非普通文件路径被拒绝。数据库写入失败时，下次启动复用已有密码文件；管理员查询失败时停止初始化。

已有管理员时不再次初始化。该文件仍是运行凭据，应按私密文件保管；当前没有管理员改密 UI/API。

## 初始实例凭据

初始密码采用 AES-GCM 加密，绑定任务与实例，15 分钟有效且只能领取一次。数据库打开时、独立的每分钟维护循环、相关任务读取和领取时都会清除到期凭据；维护循环同时删除过期会话，不依赖监控采样是否成功。

重置密码前先使原创建任务中的凭据失效，数据库清理失败则不发送改密命令。实例删除成功也会清除对应凭据。数据库字段清理不等于备份或存储介质上的安全擦除。

## 密码操作与失败恢复

创建、重置密码、启停和删除按实例的规范 ID 协调。名称与 ID 指向同一把锁，不同实例仍可并行；等待期间实例已被删除时，操作失败，不会把旧 ID 当作其他实例的名称重新定位。

改密命令发送前写入 `password_updates`，其中只保存实例 ID、时间和 Incus 操作引用，不保存密码。确定执行结束后清除记录；请求超时或连接异常不代表 Incus 命令已结束。

有未完成记录时，后续改密、启停和删除先查询 Incus 操作状态。确认终态后才能继续，仍在运行时拒绝冲突操作。此保护在 Agent 重启后继续生效，原请求不会因事后对账而变为成功，也不会重新交付原密码。

如果操作引用缺失或无法确认，当前实现保持阻断，需要人工恢复：停止 Agent，确认对应 Incus 操作及实例内改密进程均已结束，备份状态库，再按确切 `instance_id` 清理对应的 `password_updates` 记录，重启后重新设置密码。当前未提供此恢复步骤的 UI/API，不应通过反复重试或批量清空记录跳过确认。

## Token 界面

Token 列表与网络、CPU 设置独立加载。签发过程中禁止重复提交；新 Token 只显示在当前签发结果中，可手动清除，列表不返回原文。撤销需要确认，失败显示错误并允许重试；撤销成功后，即使列表刷新失败，该行也保持“已撤销”。离开页面后，迟到响应不会恢复已清除的秘密或覆盖新页面状态。
